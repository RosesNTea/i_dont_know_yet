### Contributing
1. Fork the repository
2. Download the Godot game engine [here](https://godotengine.org/download)
3. Clone your repository to your device
4. Open your cloned folder in Godot
5. Submit your changes via a PR

This project was deployed on [itch.io](https://itch.io). To put your own project on itch, follow [this guide](https://www.youtube.com/watch?v=9-lBiLMWynE).
